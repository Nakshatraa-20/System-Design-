vertical scaling
scaling means increasing the systems capacity to handle work

vertical scaling is when you increase resources of a single machine
 more cpu cores, more ram, more storage and more network capacity

 it is also called scaling up.
is often simpler because aplication can continue running on one machine 

a strong sever can also fail, you are dependent on a single machine
