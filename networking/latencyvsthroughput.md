Transmission delay is how long it takes to send the bits onto the link.

Propagation delay is how long the signal takes to travel to the destination.

latency measures time while throughput measures how much data is transferred in a given amount of time

There are two important performance questions.

Latency: How long does User B wait before the issue appears?

Throughput: How many issue updates can the system process and deliver per second?
